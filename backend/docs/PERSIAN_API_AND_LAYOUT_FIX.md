پیام‌های پاسخ سرور و خطاها فارسی شدند. کلیدهای JSON، کد خطا، شناسه‌ها و مقادیر قراردادی enum تغییر نکردند. اطلاعات ثبت‌شده کاربران و داده‌های نمونه قبلی در دیتابیس تغییر نکردند.

مسیر دریافت قالب:
GET /api/invoice-print-layouts/a4-landscape
نیازمند توکن و مجوز CompanySettings.Read است.
برای ذخیره PUT همان مسیر با مجوز CompanySettings.Update و بدنه شامل layout و version استفاده کنید.
در پاسخ GET، layout تنظیمات قابل ویرایش و version نسخه ذخیره‌سازی است. برای ذخیره version دریافتی را ارسال کنید.
نبود فایل تنظیمات باعث ۴۰۴ نمی‌شود؛ تنظیمات پیش‌فرض برمی‌گردد.

در بررسی، DLL ساخت قبلی ساعت ۱۸:۳۵ بود و کنترلر ساعت ۱۸:۵۱ اضافه شده بود. ساخت تازه انجام شد. بک‌اند در حال اجرا باید متوقف و با ساخت جدید اجرا شود:
dotnet run --project Accounting.Api.csproj --launch-profile https

تأیید: هر سه قالب در میزبان آزمایشی HTTP پاسخ ۲۰۰ دادند. خطای قالب نامعتبر، مسیر ناموجود، اعتبارسنجی مدل، اعتبارسنجی پیش‌فرض و خطای موجودی فارسی بودند. ۱۲۶ تست پروژه موفق شدند. دیتابیس اصلی در این بررسی تغییر نکرد.
