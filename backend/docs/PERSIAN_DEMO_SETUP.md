# راه‌اندازی نسخه نمایشی فارسی

کل پوشه backend را منتقل کنید؛ چهار پروژه و docs باید کنار هم بمانند. کتابخانه‌های گزارش‌ساز، فونت، قالب و مجوز خصوصی هنگام Publish کپی می‌شوند. اگر انتقال از طریق Git است، فایل خصوصی مجوز را جداگانه منتقل کنید چون در Git نادیده گرفته شده است.

## اجرا با سورس روی ویندوز

نیازمندی‌ها: SDK دات‌نت ۸ یا جدیدتر، زمان اجرای ASP.NET Core 8 و Windows Desktop 8، و SQL Server قابل دسترسی. کاربر دیتابیس باید دسترسی ایجاد دیتابیس/جداول و اجرای Migrationها را داشته باشد.

از پوشه backend:

```powershell
.\docs\Start-PersianDemo.ps1 -ConnectionString "Server=localhost;Database=AccountingPersianDemo;Trusted_Connection=True;TrustServerCertificate=True"
```

اسکریپت کلید تصادفی ورود را برای همین اجرا تولید می‌کند و چاپ نمی‌کند. برای حفظ نشست‌ها بین اجراها، JwtSettings__Secret را با کلید ثابت حداقل ۳۲ نویسه تنظیم کنید. برای HTTPS محلی، در صورت نیاز dotnet dev-certs https --trust را اجرا کنید.

در اولین اجرا، Migrationها و سپس Seed در یک تراکنش اجرا می‌شوند. برای ارائه کاملاً فارسی از دیتابیس جدید و خالی استفاده کنید؛ اطلاعات واقعی و نمونه قدیمی بازنویسی یا پاک نمی‌شوند.

## کاربران نمایشی

رمز پیش‌فرض تمام حساب‌ها: `Demo1405!`

| ایمیل ورود | نام | نقش |
|---|---|---|
| admin@demo.local | رضا مدیر | مدیر سامانه |
| owner@demo.local | علی رضایی | مدیر کسب‌وکار |
| chief@demo.local | مریم محمدی | سرپرست حسابداری |
| accountant@demo.local | محمد احمدی | کارشناس حسابداری |
| warehouse@demo.local | حسن کریمی | مسئول انبار |
| sales@demo.local | سارا حسینی | کارشناس فروش |

رمز دیگر را با DemoPassword اسکریپت یا Seeding__DemoPassword تنظیم کنید؛ فقط هنگام ایجاد کاربر جدید اعمال می‌شود. رمز کاربر موجود تغییر نمی‌کند. ایمیل شناسه فنی ورود است؛ نام و نقش نمایشی فارسی است.

## داده‌های اولیه

مشخصات شرکت ایرانی و اطلاعات لازم برای چاپ؛ سه شعبه تهران، اصفهان و شیراز و انبارهایشان؛ شش کاربر و نقش فارسی؛ پنج واحد، پنج دسته‌بندی، نوزده کالا/خدمت/هزینه/دارایی؛ هفت طرف حساب؛ پنج حساب صندوق/بانک ریالی؛ موجودی افتتاحیه، هشت سفارش، هجده فاکتور، پانزده پرداخت و پانزده چک/سفته ساخته می‌شوند. گردش انبار فاکتورها، جمع مبالغ و مانده‌ها هماهنگ‌اند.

هویت‌ها و اطلاعات بانکی ساختگی و برای نمایش‌اند. نرخ‌های نمونه مطابق قواعد فعلی برنامه حفظ شده‌اند. این اطلاعات تأیید قانونی/مالیاتی ندارند.

اجرای مجدد داده‌ها را تکرار نمی‌کند. کاربران تک‌به‌تک بررسی می‌شوند؛ وجود مدیر مانع ایجاد حساب‌های مفقود دیگر نمی‌شود. جداول تجاری دارای داده بازنویسی نمی‌شوند. کد مجوزها، IRR، نام فیلدها و enumها برای سازگاری فنی حفظ شده‌اند.

## خروجی قابل‌انتقال

از پوشه backend:

```powershell
dotnet publish .\Accounting.Api\Accounting.Api.csproj -c Release -r win-x64 --self-contained true -o .\Accounting.Api\bin\PersianDemoPortable
```

کل خروجی را منتقل کنید. برای اجرای Accounting.Api.exe نصب دات‌نت لازم نیست. ConnectionStrings__Default، JwtSettings__Secret و Seeding__Enabled=true را در مقصد تنظیم کنید. آدرس اجرا با ASPNETCORE_URLS و مبدأ فرانت با Cors__AllowedOrigins__0 قابل تنظیم است. HTTPS نیازمند گواهی مقصد است.

پس از آماده‌شدن داده‌ها، می‌توانید Seeding__Enabled=false بگذارید. Migration همچنان در راه‌اندازی اجرا می‌شود.

## بررسی

آزمون مستقل دیتابیس حافظه‌ای خالی، نام‌ها و نقش‌های فارسی، ورود، مجوز مدیر فارسی، هویت‌های چاپ، روابط شعبه/پرداخت، جمع فاکتور، گردش انبار و اجرای مجدد بدون تکرار را بررسی می‌کند. این آزمون اتصال SQL Server یا Migrationها را اجرا نمی‌کند. دیتابیس فعلی کاربر تغییر نکرده است.
