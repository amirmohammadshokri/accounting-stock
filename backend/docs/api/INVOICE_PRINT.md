# چاپ صورتحساب با Stimulsoft

دکمهٔ «چاپ فاکتور» در لیست و صفحهٔ نمایش/ویرایش فاکتور، PDF را در پنجرهٔ
جدید باز می‌کند. از ابزارهای نمایشگر PDF مرورگر برای چاپ یا دانلود استفاده کنید.
این قابلیت، قالب چاپی صورتحساب است و هیچ اتصالی به سامانهٔ مؤدیان ندارد.

## راه‌اندازی

1. تغییرات دیتابیس در migration `20261014133224_AddInvoicePrintIdentity` است.
   اسکریپت معادل `InvoicePrintIdentity.sql` برای SQL Server آماده شده و روی
   دیتابیس اجرا نشده است. برنامه نیز هنگام شروع، migrationهای اجرا‌نشده را
   مطابق رفتار قبلی خود اجرا می‌کند. اسکریپت، اطلاعات فعلی را حذف نمی‌کند.
2. در تنظیمات شرکت، شماره اقتصادی، شناسه ملی، کدپستی و نشانی را تکمیل کنید.
3. در طرف حساب، شناسه ملی/کد ملی، کدپستی و نشانی را تکمیل کنید؛ برای طرف
   حساب شرکتی، شماره اقتصادی هم لازم است. اگر داده‌ای ناقص باشد، چاپ با
   پیام شامل نام فیلدهای ناقص متوقف می‌شود.
4. بک‌اند را با نسخهٔ جدید اجرا کنید و رابط کاربری جدید را بارگذاری کنید.
5. برای خروجی بدون نشان آزمایشی، لایسنس معتبر Stimulsoft را در تنظیمات امن
   `Stimulsoft:LicenseKey` یا متغیر محیطی `Stimulsoft__LicenseKey` وارد کنید.
   کلید ارائه‌شده در فایل خصوصی `Reporting/stimulsoft-license.private.json` قرار دارد؛
   فایل از Git مستثنا و همراه Build/Publish کپی می‌شود. تنظیمات محیطی بر فایل اولویت دارد.
   بدون کلید، موتور در حالت آزمایشی
   کار می‌کند و روی PDF نشان Trial قرار می‌دهد.

## قرارداد API

`GET /api/invoices/{id}/pdf` با مجوز `Invoice.Read` خروجی `application/pdf`
می‌دهد. دادهٔ فاکتور مطابق دسترسی شعبهٔ کاربر خوانده می‌شود. فاکتور حذف‌شده
یا خارج از دسترسی، خطای ۴۰۴ می‌دهد. پاسخ PDF قابل cache نیست. درخواست رابط
کاربری از HttpClient و همان زنجیرهٔ احراز هویت پروژه عبور می‌کند؛ توکن در
نشانی پنجرهٔ PDF قرار نمی‌گیرد.

قالب A4 افقی، فارسی و راست‌به‌چپ است. شامل مشخصات طرفین، تاریخ شمسی،
اقلام، واحد تاریخی هر ردیف، تخفیف، مالیات، جمع ریالی، مبلغ به حروف، کسور،
مبلغ قابل پرداخت، مانده و محل امضا است. جمع‌ها از فاکتور ذخیره‌شده خوانده
می‌شوند. در فاکتور خرید، فروشنده طرف حساب و خریدار شرکت خودتان است.
فاکتور دارای ارز غیرریالی با این قالب چاپ نمی‌شود.

## ویرایش قالب

قالب قابل ویرایش در `Accounting.Infrastructure/Reporting/Invoice.mrt` قرار
دارد. آن را در Stimulsoft Designer باز کنید. منابع داده `Invoice` و `Lines`
هستند؛ اطلاعات نمونهٔ مشتری داخل قالب ذخیره نشده است. فونت آزاد Vazirmatn
همراه با مجوز OFL در `Reporting/Fonts` توزیع می‌شود و در PDF درج می‌شود.

سازندهٔ قالب `InvoiceReportTemplate.cs` است. برای بازسازی قالب و تولید دو
نمونهٔ ساختگی یک‌صفحه‌ای و چندصفحه‌ای:

```powershell
dotnet run --project backend/docs/tests/InvoicePrintPreview/InvoicePrintPreview.csproj -- --template
```

خروجی‌ها در `backend/docs/output/pdf` ذخیره می‌شوند. اجرای دستور بدون
`--template` فقط PDFهای نمونه را با قالب فعلی تولید می‌کند. این بررسی روی
ویندوز انجام شده است؛ بازسازی قالب از `System.Drawing` استفاده می‌کند.

## نتیجهٔ بررسی

Build بک‌اند و Angular موفق بود و هر ۱۱۹ تست مجموعهٔ کامل گذشت.
خروجی نمونهٔ تک‌صفحه‌ای و چهارصفحه‌ای با اندازهٔ A4 افقی رندر و بازبینی شد.
مدل EF نیز با migration هماهنگ است. اسکریپت SQL روی دیتابیس اجرا نشده است.

## نسخهٔ محلی 2024.3.2

بستهٔ NuGet موتور 2026.4.1 حذف شد. DLLهای امضاشدهٔ ارائه‌شده با نسخهٔ
2024.3.2.0 در `Accounting.Infrastructure/libs/Stimulsoft/2024.3.2` قرار دارند
و ارجاع‌ها نسبی‌اند. API، Infrastructure و ابزارهای چاپ به `net8.0-windows`
تغییر کرده‌اند؛ برای اجرا Windows Desktop Runtime 8 و ASP.NET Core Runtime 8
لازم است. این فایل‌های دسکتاپ برای استقرار Linux مناسب نیستند.

برای انتقال پروژه، پوشهٔ libs و فایل خصوصی لایسنس را هم منتقل کنید؛ فایل
خصوصی در Git نیست. برای استقرار، خروجی کامل Publish را به پوشهٔ تمیز منتقل
کنید تا DLLهای Stimulsoft قدیمی و جدید با هم مخلوط نشوند.

راهنمای تحویل قالب به فرانت در `INVOICE_TEMPLATE_HANDOFF.txt` است. ویرایشگر
داخل مرورگر و API ذخیرهٔ قالب جزو پیاده‌سازی فعلی نیست؛ قالب با Designer
مستقل ویرایش و فایل `.mrt` جدید به بک‌اند تحویل می‌شود.

## خروجی مستقل ویندوز

برای انتقال بدون نیاز به نصب .NET روی مقصد، از خروجی self-contained استفاده کنید:

```powershell
dotnet publish backend/Accounting.Api/Accounting.Api.csproj -c Release -r win-x64 --self-contained true -o publish/accounting-api
```

پوشهٔ خروجی را کامل منتقل کنید. این خروجی خصوصی بک‌اند است و شامل فایل
لایسنس خواهد بود؛ آن را به فرانت ندهید. برای ویرایش قالب، بستهٔ مستقل
`invoice-template-2024.3.2.zip` شامل قالب، دادهٔ ساختگی، فونت و راهنما آماده است.
نمونهٔ PDF با موتور 2024.3.2 تولید و بدون نشان Trial مشاهده شد. همهٔ ۱۱۹
تست با Runtime 8 جداگانه گذشت؛ نصب سیستمی Runtime با خطای 1618 (در حال
اجرا بودن نصب دیگر ویندوز) انجام نشد.

خروجی مستقل در `Accounting.Api/bin/Stimul2024Portable` نیز واقعاً اجرا شد؛
در محیط Testing و بدون اتصال دیتابیس، API محافظت‌شده پاسخ ۴۰۱ مورد انتظار داد.
فایل‌های منتشرشده با هش DLLهای اصلی تطبیق داده شدند.
