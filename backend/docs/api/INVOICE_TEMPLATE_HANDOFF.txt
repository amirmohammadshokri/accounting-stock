فایل‌ها و اطلاعات لازم برای ویرایش قالب فاکتور
=============================================

بستهٔ invoice-template-2024.3.2.zip را به مسئول قالب/فرانت بدهید.
نسخهٔ موتور پروژه: Stimulsoft 2024.3.2 برای .NET 8 دسکتاپ.

محتویات بسته:
1. Invoice.mrt: قالب فعلی قابل ویرایش.
2. invoice-sample-data.json: دادهٔ ساختگی برای شناخت فیلدها.
3. invoice-sample-data.xml: همان داده همراه با schema.
4. Vazirmatn-Regular.ttf و OFL.txt: فونت و مجوز آن.
5. invoice-preview.pdf: نمونهٔ خروجی برای مقایسهٔ ظاهر.

مراحل ویرایش:
- فونت را روی سیستم طراحی نصب کنید.
- از Stimulsoft Designer سازگار با نسخهٔ 2024.3.2 استفاده کنید و Invoice.mrt را باز کنید.
- متن، چیدمان، اندازه‌ها، خطوط و محل امضا قابل ویرایش هستند.
- نام منابع Invoice و Lines و نام ستون‌ها را تغییر ندهید.
- منبع Invoice یک رکورد سربرگ و جمع‌ها دارد؛ Lines ردیف‌های اقلام را دارد.
- NameInSource منابع باید InvoicePrint.Invoice و InvoicePrint.Lines باقی بماند.
- مقدارها توسط بک‌اند ثبت می‌شوند؛ دیتابیس و connection string داخل قالب لازم نیست.
- فیلدهای نمایشی در دادهٔ چاپ رشته هستند؛ مبلغ‌ها از قبل به ریال و تاریخ به شمسی قالب‌بندی شده‌اند.
- صفحه A4 افقی، واحد اندازه‌گیری Centimeters و فونت Vazirmatn را حفظ کنید.
- برای PDF از محاسبات ثبت‌شدهٔ فاکتور استفاده می‌شود؛ تغییر محاسبات در قالب توصیه نمی‌شود.

تحویل قالب جدید:
- فقط فایل ویرایش‌شدهٔ Invoice.mrt را برگردانید.
- این فایل در Accounting.Infrastructure/Reporting/Invoice.mrt جایگزین می‌شود.
- پروژه دوباره Build/Publish می‌شود تا قالب به Reporting/Invoice.mrt در خروجی برنامه برسد.
- API قبلی GET /api/invoices/{id}/pdf و دکمهٔ چاپ بدون تغییر باقی می‌مانند.
- برای تست از backend اجرا کنید:
  dotnet run --project docs/tests/InvoicePrintPreview/InvoicePrintPreview.csproj
- هنگام تست ویرایش دستی، --template را استفاده نکنید؛ آن گزینه قالب را از کد بازسازی می‌کند.

محدودهٔ فعلی:
ویرایشگر Stimulsoft داخل مرورگر و API آپلود/ذخیرهٔ قالب در پروژه پیاده‌سازی نشده است.
این بسته برای ویرایش فایل با Designer مستقل و تحویل فایل جدید است.
اگر هدف ویرایش قالب توسط کاربر از داخل خود وب‌اپ باشد، باید Designer وب و APIهای
دریافت/ذخیره/پیش‌نمایش قالب با مجوز مناسب، به‌صورت قابلیت جداگانه اضافه شوند.

کلید لایسنس و DLLهای بک‌اند عمداً در این بسته نیستند و نباید به فرانت ارسال شوند.
